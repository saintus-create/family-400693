# Rebuilt on the standard Fern structure

The site was rebuilt end to end to follow the standard Fern repository layout:

- **Standard Fern layout.** Pages live in `fern/pages/`, assets in `fern/assets/`, and every page is listed explicitly in the `fern/docs.yml` navigation — no folder auto-discovery, no side-channel generation.
- **Full statutory text, LegInfo-style.** Each code is browsable as consecutive pages split at its official division boundaries (one page per code for small codes). No 162,000-page sidebar.
- **Repository slimmed from ~725 MB to ~50 MB** of corpus + content. Raw `.txt` dumps, duplicated MDX files, and Fern starter examples were removed.
- **Fixed the homepage 404** — the Family Code overview is in the Research section.
- **One publish workflow** (`publish-docs.yml`) using the Fern CLI, plus `check.yml` on PRs and `preview-docs.yml` for pull-request previews.

Section-level research works through the code pages themselves, the [corpus search](/codes/search), **Ask AI**, and the downloadable `JSONL.gz` datasets on each code's overview page.
