# California Codes

**29 California statutory codes plus the California Constitution** — **162,324 sections** of full statutory text, organized by each code's official divisions.

## How the site is organized

- Every code has an **overview page** (section counts, snapshot date, and dataset downloads) and one or more **full-text pages** split at the code's own division boundaries.
- **Corpus search** at [Search the California Code Corpus](/codes/search) streams the selected code on demand and ranks matches by citation and text.
- **Ask AI** is indexed against the same snapshot, so natural-language research questions are answered with citations.
- **Bulk data** for every code is downloadable as `JSONL.gz` from the overview pages and the [corpus manifest](https://github.com/saintus-create/family-400693/blob/main/fern/assets/corpus/manifest.json).

<Note>
This is a dated research snapshot. Verify current text, effective dates, and applicability against the [official California Legislative Information code search](https://leginfo.legislature.ca.gov/faces/codes.xhtml). This library is not legal advice.
</Note>
