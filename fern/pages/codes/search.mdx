## Search behavior

Use a code abbreviation such as `FAM`, a full code name such as “Family Code,” an exact citation such as `GOV § 6250`, or ordinary terms from the provision you are researching. The search reads only the selected compressed datasets, ranks results locally, and shows the strongest matches without placing the entire corpus into a model context window.

For AI-assisted research, use the result citations as the evidence set: ask for a broad explanation when needed, request comparisons explicitly, and require the answer to distinguish quoted text, paraphrase, inference, and uncertainty.

## Corpus coverage

The catalog includes the California Constitution and all 29 statutory codes packaged in the [corpus manifest](/assets/corpus/manifest.json). Each code page links to its complete JSONL dataset and provenance metadata.
