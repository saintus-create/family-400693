# Site overhaul — leaner, faster, focused

- **Repo size cut from ~725 MB to ~55 MB.** Removed ~493 MB of committed per-section MDX pages, ~240 MB of duplicate raw `.txt`/`.mdx` code files at the repository root, and unused Fern starter content (example OpenAPI/AsyncAPI references, onboarding pages, leftover assets).
- **Fixed the changelog.** The changelog tab referenced a `docs/changelog` folder that did not exist, which broke the build. This entry starts the changelog.
- **Fixed a broken homepage link.** The landing hero linked to `/family-code-overview`, which was never in the navigation. The Family Code overview now lives in the Research section.
- **Removed the API Reference tab.** It only contained Fern starter examples (a petstore OpenAPI spec and a streetlights AsyncAPI spec) unrelated to California legislative information.
- **One publish workflow.** Two workflows (`publish-docs.yml` and `publish-fern.yml`) raced to publish on every push to `main`. Now a single workflow validates, publishes, and re-indexes the corpus for Ask Fern.
- **Removed the self-fighting `materialize-txt-as-mdx` workflow** that regenerated unused root-level MDX files on every trigger.
- **Search unchanged in behavior, better feedback.** The corpus search still streams one compressed code at a time; it now reports per-code progress while scanning.

Section-level research continues to work through the [corpus search](/codes/search), **Ask AI**, and the downloadable `JSONL.gz` datasets on each code page.
