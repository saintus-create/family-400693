# Family Code

**1,636 sections** · **1,946 records including hierarchy nodes** · **Snapshot updated by the source: November 27, 2025**

This page is the Fern catalog entry for the `FAM` dataset. The complete section-level snapshot is preserved as compressed JSON Lines so it can be downloaded, mirrored, or indexed by a downstream search service. Individual sections can be located with the [corpus search](/codes/search) or through **Ask AI**, which is indexed against this same snapshot.

## Regeneration

Regenerate the catalog pages and compressed assets from the canonical `data/law/*.jsonl.gz` snapshot:

```bash
python3 scripts/build_fern_corpus.py /path/to/source/checkout
```

An optional section-page generator (`scripts/generate_fern_sections_mdx.py`) remains available for offline use, but its output is no longer part of the deployed site.

## Record format

Each JSONL record is either a `section` or a table-of-contents node. Section records retain the citation, operative text, history, repeal status, hierarchy path, and a stable UID such as `FAM:1`.

```json
{
  "kind": "section",
  "code": "FAM",
  "citation": "FAM § …",
  "section": "…",
  "text": "…",
  "history": "…"
}
```

<Note>
The dataset is a dated research snapshot. Verify the current text, effective date, and applicability against the official California Legislative Information source before relying on a provision.
</Note>
