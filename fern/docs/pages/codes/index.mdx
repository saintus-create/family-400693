# California Codes

This catalog packages the complete section-level snapshot from the law corpus repository into Fern-compatible static assets. It contains **29 California statutory codes plus the California Constitution**, totaling **162,324 sections** and **24,233 hierarchy records**.

## How the index works

Fern serves a standard overview page for each code and keeps the full section records as compressed JSON Lines assets for bulk download and AI indexing.

- **Catalog pages** (below) are lightweight overviews for each code.
- **Corpus search** at [Search the California Code Corpus](/codes/search) streams the selected code on demand and ranks matches by citation and text.
- **Ask AI** is indexed against the same snapshot, so natural-language research questions are answered with citations.
- **Bulk data** for every code is downloadable as `JSONL.gz` from the catalog pages and the [corpus manifest](https://github.com/saintus-create/family-400693/blob/main/fern/docs/assets/corpus/manifest.json).
- **Rebuild:** `python3 scripts/build_fern_corpus.py /path/to/source/checkout` regenerates the catalog pages and compressed assets.

<Note>
This is a dated research snapshot. Verify current text, effective dates, and applicability against the [official California Legislative Information code search](https://leginfo.legislature.ca.gov/faces/codes.xhtml).
</Note>
