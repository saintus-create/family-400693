## Text

The notice for a special rate of assessment hearing shall state all of the following:

(a) Petitions have been presented to the board praying for a determination that certain land, which need not be described in the notice, is entitled to a special rate of assessment.

(b) The names of the petitioners.

(c) The time and place set for the hearing.
