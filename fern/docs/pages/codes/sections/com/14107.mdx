## Text

Except as otherwise provided in this division, this code as it existed prior to January 1, 1976, shall apply to any questions of priority if the positions of the parties were fixed prior to January 1, 1976. In other cases questions of priority shall be determined by this code as amended by the Legislature at the 1973–74 Regular Session.
