## Text

Whenever any application made under this code is accompanied by any fee, except an application for an occupational license accompanied by a fee as specified in Section 9262, 9262.5, 11309, or 11820, or an application for a duplicate driver’s license, as required by law, and the application is refused or rejected, the fees shall be returned to the applicant, except that, whenever any application is made for the first set of special plates under subdivision (a) of Section 9262 and the application is refused or rejected, the fee for the special plates only shall be returned to the applicant or, when application is made for the first set of special plates under subdivision (1) of Section 9264 and the application is refused or rejected, the fee for the special plates shall be returned to the applicant.
