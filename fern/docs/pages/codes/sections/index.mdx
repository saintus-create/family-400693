# California Code Sections — Per-section MDX

This directory contains **2,008 sections** across **2 codes** as individual Fern MDX pages under `fern/docs/pages/codes/sections/`.

Each section is a first-class Fern page with:

- Frontmatter (`title`, `description`, `slug`, `position`) for SEO and ordering

- Canonical citation and hierarchy

- Operative text and history

- Stable `UID` (e.g. `FAM:1`, `CONS:I-1`, `GOV:985#2`) and official LegInfo link

- Previous / next navigation in statutory order

<Note>
Dated research snapshot — always verify against the [official California Legislative Information](https://leginfo.legislature.ca.gov/faces/codes.xhtml) source.
</Note>

## How to use

- **Browse:** expand **Code Sections (MDX)** in the left sidebar, pick a code, then a section. Pages are ordered by `position` (statutory order).

- **Search:** use **Search the California Code Corpus** for full-text ranking, then click a citation link which resolves to its MDX page.

- **AI search:** Fern Ask Fern can retrieve and cite these pages; they are also synced via `scripts/sync_fern_legal_corpus.py` to the Documents API.

- **Build locally:** `python3 scripts/generate_fern_sections_mdx.py --code FAM --limit 5` then `fern check`.

## Regenerate

```bash
python3 scripts/generate_fern_sections_mdx.py          # all 162k sections
python3 scripts/generate_fern_sections_mdx.py --code FAM # just Family Code
python3 scripts/generate_fern_sections_mdx.py --clean     # clean first
```
