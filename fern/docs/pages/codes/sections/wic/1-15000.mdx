## Text

Notwithstanding any provisions of Sections 29800 and 29805 of the Government Code, warrants payable to recipients of public assistance shall not include any word or abbreviation indicative of aid, assistance, charity, needy, support, or welfare. Nothing in this section prohibits the use of code numbers or other code symbols used and understood by county officers and agencies to identify the purpose and liability for which such warrants are drawn, if such code numbers or other code symbols are not generally so understood by the public.
