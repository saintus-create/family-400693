## Text

The notice shall:

(a) Be addressed to all persons owning or interested in plots in the cemetery but need not name them.

(b) Set forth in a general way the proposed changes.

(c) Set forth the reasons stated in the petition for making the changes.

(d) State the time when the hearing of the petition will be had.

(e) State that a plat showing the proposed changes is on file with the clerk of the court.
