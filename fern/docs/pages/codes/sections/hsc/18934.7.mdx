## Text

The commission shall adopt, approve, codify, and publish by reference in the California Building Standards Code the building standards in Appendix Chapter 1 of the International Existing Building Code of the International Code Council to provide minimum standards for buildings specified in that appendix, except for buildings subject to building standards adopted pursuant to Part 1.5 (commencing with Section 17910).
