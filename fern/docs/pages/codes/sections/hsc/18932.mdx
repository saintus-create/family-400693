## Text

(a) The code shall indicate the agency having responsibility vested by law for the administration of each building standard and the occupancy or occupancies affected by each building standard.

(b) The code shall include an index and reference guide.

(c) The commission shall establish the format for the code to conform it as nearly as it deems practicable with the model codes.
