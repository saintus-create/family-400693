## Text

Every person, before acting as an agent, shall file an application with the director for a license to so act. The application shall be accompanied by the application fee which is prescribed by Article 16 (commencing with Section 55861) of this chapter.

(History: Enacted by Stats. 1967, Ch. 15.)
