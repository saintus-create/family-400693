# Unemployment Insurance Code

**1,120 sections** · **1,269 records including hierarchy nodes** · **Snapshot updated by the source: July 17, 2026**

This page is the Fern catalog entry for the `UIC` dataset. The complete section-level snapshot is preserved as compressed JSON Lines so it can be downloaded, mirrored, or indexed by a downstream search service without generating one fragile documentation page per section.

## Record format

Each JSONL record is either a `section` or a table-of-contents node. Section records retain the citation, operative text, history, repeal status, hierarchy path, and a stable UID such as `UIC:1`.

```json
{
  "kind": "section",
  "code": "UIC",
  "citation": "UIC § …",
  "section": "…",
  "text": "…",
  "history": "…"
}
```

<Note>
The dataset is a dated research snapshot. Verify the current text, effective date, and applicability against the official California Legislative Information source before relying on a provision.
</Note>
