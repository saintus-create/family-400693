# Elections Code

**2,376 sections** · **2,821 records including hierarchy nodes** · **Snapshot updated by the source: May 29, 2026**

This page is the Fern catalog entry for the `ELEC` dataset. The complete section-level snapshot is preserved as compressed JSON Lines so it can be downloaded, mirrored, or indexed by a downstream search service. The same data is also rendered as **per-section MDX pages** under `Code Sections (MDX)` — one Fern MDX page per section (e.g. `/codes/elec/1`), generated from the canonical corpus.

## MDX generation

Regenerate the catalog and/or the per-section MDX from the canonical `data/law/*.jsonl.gz` snapshot:

```bash
# catalog (overview pages + compressed assets)
python3 scripts/build_fern_corpus.py /path/to/source/checkout

# per-section MDX (one .mdx per statutory section)
python3 scripts/generate_fern_sections_mdx.py --code ELEC   # single code
python3 scripts/generate_fern_sections_mdx.py                 # all 30 codes (~162k files)
```

## Record format

Each JSONL record is either a `section` or a table-of-contents node. Section records retain the citation, operative text, history, repeal status, hierarchy path, and a stable UID such as `ELEC:1`.

```json
{
  "kind": "section",
  "code": "ELEC",
  "citation": "ELEC § …",
  "section": "…",
  "text": "…",
  "history": "…"
}
```

<Note>
The dataset is a dated research snapshot. Verify the current text, effective date, and applicability against the official California Legislative Information source before relying on a provision.
</Note>
