# Financial Code

**3,320 sections** · **3,824 records including hierarchy nodes** · **Snapshot updated by the source: July 10, 2026**

This page is the Fern catalog entry for the `FIN` dataset. The complete section-level snapshot is preserved as compressed JSON Lines so it can be downloaded, mirrored, or indexed by a downstream search service without generating one fragile documentation page per section.

## Files

- [Download the `FIN.jsonl.gz` dataset](https://github.com/saintus-create/family-400693/blob/main/fern/docs/assets/corpus/law/FIN.jsonl.gz)
- [Download the corpus manifest](https://github.com/saintus-create/family-400693/blob/main/fern/docs/assets/corpus/manifest.json)
- [Browse the official California code search](https://leginfo.legislature.ca.gov/faces/codes.xhtml)

## Record format

Each JSONL record is either a `section` or a table-of-contents node. Section records retain the citation, operative text, history, repeal status, hierarchy path, and a stable UID such as `FIN:1`.

```json
{
  "kind": "section",
  "code": "FIN",
  "citation": "FIN § …",
  "section": "…",
  "text": "…",
  "history": "…"
}
```

<Note>
The dataset is a dated research snapshot. Verify the current text, effective date, and applicability against the official California Legislative Information source before relying on a provision.
</Note>
