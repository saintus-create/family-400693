# Government Code

**21,863 sections** · **24,789 records including hierarchy nodes** · **Snapshot updated by the source: September 02, 2026**

This page is the Fern catalog entry for the `GOV` dataset. The complete section-level snapshot is preserved as compressed JSON Lines so it can be downloaded, mirrored, or indexed by a downstream search service. The same data is also rendered as **per-section MDX pages** under `Code Sections (MDX)` — one Fern MDX page per section (e.g. `/codes/gov/1`), generated from the canonical corpus.

## MDX generation

Regenerate the catalog and/or the per-section MDX from the canonical `data/law/*.jsonl.gz` snapshot:

```bash
# catalog (overview pages + compressed assets)
python3 scripts/build_fern_corpus.py /path/to/source/checkout

# per-section MDX (one .mdx per statutory section)
python3 scripts/generate_fern_sections_mdx.py --code GOV   # single code
python3 scripts/generate_fern_sections_mdx.py                 # all 30 codes (~162k files)
```

## Record format

Each JSONL record is either a `section` or a table-of-contents node. Section records retain the citation, operative text, history, repeal status, hierarchy path, and a stable UID such as `GOV:1`.

```json
{
  "kind": "section",
  "code": "GOV",
  "citation": "GOV § …",
  "section": "…",
  "text": "…",
  "history": "…"
}
```

<Note>
The dataset is a dated research snapshot. Verify the current text, effective date, and applicability against the official California Legislative Information source before relying on a provision.
</Note>
