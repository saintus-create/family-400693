The **California Family Code** contains statutes governing marriage, domestic partnerships, parentage, custody, support, adoption, and related family-law matters.

<Note>
This page is an orientation guide, not legal advice. Always verify the current text and applicability of a statute through an official source or a qualified California attorney.
</Note>

## Start with the official code

- [California Family Code](https://leginfo.legislature.ca.gov/faces/codes_displayexpandedbranch.xhtml?tocCode=FAM) — browse the code by division, part, chapter, and section.
- [California Legislative Information](https://leginfo.legislature.ca.gov/) — search bills, codes, statutes, and legislative materials.

## How to read a code section

1. **Identify the section number.** Use the citation in a court filing, order, or secondary source.
2. **Read the full section and nearby provisions.** Definitions, exceptions, and cross-references often appear in adjacent sections.
3. **Check the effective date and amendments.** A section may have historical versions or delayed operative dates.
4. **Confirm the procedural context.** A statute may apply differently depending on the proceeding, court, or requested remedy.
